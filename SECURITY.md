# Security policy

## Supported release

The first planned public release is **2.1.0.3**. Only the current published release is intended to receive fixes; older builds are not supported.

## Reporting a vulnerability

Do **not** put unpatched vulnerability details, credentials, customer IP addresses or reproduction data from private networks into public GitHub issues.

If GitHub's **Report a vulnerability** option is available on this repository, use it to disclose privately to the maintainer. If not, open a public issue requesting a private contact method **without sharing exploit details or sensitive data**.

This project is a diagnostic tool. It should only be used on networks that you own or are authorized to test.
